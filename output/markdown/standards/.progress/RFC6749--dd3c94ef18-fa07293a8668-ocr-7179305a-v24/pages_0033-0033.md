# <u>`4.3.3.  Access Token Response`</u> 

If the access token request is valid and authorized, the authorization server issues an access token and optional refresh token as described inSection 5.1.  If the request failed client authentication or is invalid, the authorization server returns an error response as described inSection 5.2.
