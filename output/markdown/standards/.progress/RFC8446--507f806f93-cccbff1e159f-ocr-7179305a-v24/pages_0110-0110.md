```
B.4.  Cipher Suites
```

A symmetric cipher suite defines the pair of the AEAD algorithm and hash algorithm to be used with HKDF.  Cipher suite names follow the naming convention:

```
      CipherSuite TLS_AEAD_HASH = VALUE;
```

|`+-----------+------------------------------------------------+`<br>`| Component | Contents                                       |`<br>`+-----------+------------------------------------------------+`<br>`| TLS       | The string "TLS"                               |`<br>`|           |                                                |`|
|---|
|<br>`| AEAD      | The AEAD algorithm used for record protection  |`<br>`|           |                                                |`|
|<br>`| HASH      | The hash algorithm used with HKDF              |`<br>`|           |                                                |`|
|<br>`| VALUE     | The two-byte ID assigned for this cipher suite |`<br>`+-----------+------------------------------------------------+`|



This specification defines the following cipher suites for use with TLS 1.3.

```
              +------------------------------+-------------+
              | Description                  | Value       |
              +------------------------------+-------------+
              | TLS_AES_128_GCM_SHA256       | {0x13,0x01} |
              |                              |             |
              | TLS_AES_256_GCM_SHA384       | {0x13,0x02} |
              |                              |             |
              | TLS_CHACHA20_POLY1305_SHA256 | {0x13,0x03} |
```
